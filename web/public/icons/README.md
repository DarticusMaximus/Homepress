# Homepress icons

Lettermark: white capital **H** on `#0a0a0a`.

- `homepress-mark.svg` — source for any-purpose geometry
- `icon-192.png` / `icon-512.png` — PWA `purpose: any`
- `icon-512-maskable.png` — same mark with extra padding so the H stays inside the center ~80% safe zone

Regenerate from repo root:

```bash
node scripts/generate-homepress-icons.mjs
```
